# Security policy

Please report vulnerabilities privately; do not open a public issue.

- **GitHub:** [report a vulnerability](https://github.com/we-apranik/apranik/security/advisories/new)
- **Email:** we-apranik@proton.me

What to include, what is in scope and what to expect are on the
[security page](https://we-apranik.github.io/apranik/get-started/security/).

Apranik has not been independently audited. There is no release yet; fixes go to `main`.
